## 👋 关于我

> **12 年全栈开发经验**，以 **React** 为起点，逐步拓展至 Vue、小程序与 **Node.js** 等主流生态，具备前端、后端到客户端的多端交付能力。近 5 年以独立开发者身份深耕 **Rust** 底层与**高频交易系统**开发，完整经历过从需求分析、架构设计到线上部署的全生命周期。近两年将 **AI 辅助编程**深度融入工作流，在严格保障代码质量的前提下，显著提升交付效率。

- 🦀 **底层系统**：用 Rust(Axum / Tokio) 从零构建微秒级高频交易系统 —— 行情聚合、本地订单簿(LOB)、多策略并行引擎、风控与监控全链路，7×24h 稳定运行。
- ⚛️ **前端架构**：React / Vue / TypeScript，组件库封装、工程化治理、首屏与 SEO 极致优化、老旧系统重构。
- 🌐 **高并发后端**：实时数据流、WebSocket 多源聚合、分布式状态同步、PostgreSQL。
- 💰 **实战战绩**：曾以 Node.js + RxJS 套利策略（发现杠杆代币交易对规则性设计缺陷）实盘运行 7 个月、累计数十万美元收益，是转向 Rust 高频系统的直接驱动力。
- 🤖 **AI 提效**：自 2023 年起深度使用 AI 编程助手，聚焦业务建模与架构设计。

> 核心聚焦：**老旧系统现代化重构 · 前端工程化体系治理 · 高并发性能攻坚 · 全链路业务落地** —— 专注化解技术债务、优化页面性能、提升研发效能与保障高并发稳定性，致力于解决企业级系统的核心难题。
