## 👋 关于我

> 12 年全栈开发经验，技术栈以 **React** 为起点，逐步覆盖 Vue、小程序与 **Node.js**。近 5 年以独立开发者身份深入 **Rust** 底层与**高频交易系统**开发，具备从需求分析、架构设计到线上部署的全生命周期能力。近两年将 **AI 辅助编程**深度融入工作流，在保障代码质量的前提下显著提升交付效率。

- 🦀 **底层系统**：用 Rust(Axum / Tokio) 从零构建微秒级高频交易系统 —— 行情聚合、本地订单簿(LOB)、策略引擎、风控与监控全链路。
- ⚛️ **前端架构**：React / Vue / TypeScript，组件库封装、工程化治理、首屏与 SEO 极致优化、老旧系统重构。
- 🌐 **高并发后端**：实时数据流、WebSocket 多源聚合、分布式状态同步、PostgreSQL。
- 🤖 **AI 提效**：自 2023 年起深度使用 AI 编程助手，聚焦业务建模与架构设计。
